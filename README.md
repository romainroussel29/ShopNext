# 🛍️ ShopNext

> Une application e-commerce moderne et haut de gamme développée en React, Vite et **Vanilla CSS natif** (sans aucun framework de style), conçue comme pièce maîtresse de portfolio.

![ShopNext Banner](https://images.unsplash.com/photo-1472851294608-062f824d29cc?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Fonctionnalités & Points Forts

- **Design System Exclusif (Vanilla CSS) :** Interface lumineuse, épurée et sophistiquée (style e-commerce de luxe), entièrement codée à la main (variables CSS, Flexbox/Grid, modales, ombres douces et transitions fluides).
- **Consommation d'API REST :** Récupération dynamique des produits et des catégories depuis la [Fake Store API](https://fakestoreapi.com/).
- **Filtrage & Recherche Avancée :** Filtrage instantané par catégories et recherche textuelle en temps réel.
- **Panier Persistant :** Gestion complète du panier (ajout, modification des quantités, calcul automatique du total) avec persistance via `localStorage`.
- **Tunnel de Commande (Checkout) :** Modale de paiement interactive, formulaire de livraison contrôlé et écran de confirmation avec génération d'un numéro de commande unique.

---

## 🛠️ Stack Technique

- **Front-end :** React (Hooks, gestion d'état)
- **Outil de build :** Vite
- **Style :** CSS Natif / Vanilla CSS (Architecture modulaire et personnalisée)
- **Données :** API REST externe & Web Storage (`localStorage`)
